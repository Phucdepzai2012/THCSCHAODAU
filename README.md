# CỔNG THÔNG TIN ĐIỆN TỬ - TRƯỜNG THCS NGÔ VĂN SỞ

Hệ thống Website Cổng thông tin điện tử & Quản lý nội dung (CMS) trường học hoàn chỉnh viết bằng Python Flask & SQLite.

## Tính năng chính
- 📰 Quản lý & đăng tải bài viết, tin tức nổi bật, thời khóa biểu, tư vấn học đường.
- 🖼️ Hệ thống Quản lý Mọi Banner (Banner đầu trang, Banner giữa trang, Banner cột phải) có gắn link đích.
- 📊 Tra cứu điểm & kết quả rèn luyện học sinh theo Mã HS hoặc Họ tên.
- 📁 Quản lý và tải về Văn bản chỉ đạo, công văn điện tử.
- ✉️ Hòm thư góp ý trực tuyến từ phụ huynh và học sinh.
- 🔒 Trang quản trị Admin bảo mật cao (Hỗ trợ đổi mật khẩu, mã hóa SHA-256).

## Hướng dẫn Triển khai 24/7 Miễn phí trên Render.com
1. Đăng ký tài khoản tại [Render.com](https://render.com).
2. Bấm **New +** → **Web Service**.
3. Chọn Repository GitHub này.
4. Render sẽ tự động nhận diện cấu hình từ `render.yaml` và `Procfile` để chạy website 24/7!
